# Guía de Kioto · 11–15 diciembre 2026

Web estática en español, preparada para GitHub Pages. No necesita backend, base de datos, dependencias ni proceso de compilación.

## Vista previa local

Abre `index.html` con cualquier navegador.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub (por ejemplo, `kyoto-diciembre-2026`).
2. Sube `index.html` y `README.md` a la raíz del repositorio.
3. En GitHub, abre **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`; guarda los cambios.
6. GitHub publicará la página en una dirección del tipo `https://TU-USUARIO.github.io/kyoto-diciembre-2026/`.

## Actualizar el contenido

Edita `index.html`. Los apartados están organizados por comentarios implícitos y encabezados visibles: resumen, detalle de cada día, lugares alternativos, consejos y fuentes. No hace falta tocar el CSS o JavaScript para cambiar textos, horarios o enlaces.

## Compartir o imprimir

Comparte la URL pública de GitHub Pages con el grupo. El botón **Imprimir / guardar PDF** utiliza la función de impresión del navegador; en el diálogo, selecciona **Guardar como PDF**.

## Notas

- Los enlaces de recorrido abren Google Maps y permiten ajustar el itinerario y el transporte el día de la visita.
- La web no almacena datos personales ni envía información a ningún servidor.
- Los horarios de templos y eventos pueden cambiar; comprueba las fuentes oficiales antes de ir.
